# bitgamer-demo

Built output of the **BitGamer.io** portfolio simulation, served by GitHub Pages.

This repository contains only the compiled static site. Do not edit it by hand: it is overwritten on every deploy. Source, docs and tests live in the BitGamer-Info project by [Victor Williams](https://github.com/Vaporjawn).

Everything on the site is mock data. BTK is not a real token and no money moves.
